## Description

Comprehensive exit criterion verifying that every FQDN pattern generated by the
platform resolves correctly through the internal DNS system.

Covers:
- Product A records (multiple products)
- Container / workload A records (multiple containers across products)
- Node A records
- SRV records for service discovery (`_sparql._tcp.product.picloud.local`)
- TXT records for product metadata (version) and cluster info (cluster_id, version)
- Non-authoritative domain returns NxDomain
- Cache invalidation on WorkloadRescheduled and ProductDeployed events
- InMemoryDnsRegistry product isolation (cross-product negative test)
- Deregistration cleans up DNS entries without affecting other products
